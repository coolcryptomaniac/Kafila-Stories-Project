# Kafila Stories

A premium travel-brand website that runs entirely on free infrastructure:
static hosting on GitHub Pages, content as JSON in this repository, and
enquiries into a Google Sheet through Google Apps Script.

No server. No database bill. No card on file.

---

## What is here

```
index.html          Home — cinematic hero, featured journeys, founders, reviews
journeys.html       All journeys, filterable by collection
package.html        Journey template (?slug=…) — the fallback renderer
tours/<slug>/       Pre-rendered journey pages, generated by build.js — these are
                    what search engines actually index
founders.html       Travel With The Founders — group departures
about.html          About, Why Kafila, brand vision, founder
contact.html        Contact details, map, and the enquiry form
admin/              The admin console

data/site.json      Contact, payment, hero, about, reviews — all site settings
data/packages.json  Every journey
data/trips.json     Group departures

config.js           The only file you must edit to go live
build.js            Pre-renders tour pages + sitemap.xml + robots.txt
apps-script/Code.gs Paste into Google Apps Script — this is the backend
```

## Run it locally

The site loads JSON over `fetch`, so opening `index.html` straight from
disk will not work. Serve it instead:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

Or `npx serve` if you prefer Node.

## Deploy

1. Push this folder to a GitHub repository.
2. Settings → Pages → Source: **GitHub Actions**.
3. Push to `main`. The workflow pre-renders the tour pages and publishes.

Full instructions, including the Google Sheet backend, are in **SETUP.md**.

## Editing content

Everything is editable from `/admin/` — packages, itineraries, prices,
group trips, payment details, contact details and the homepage hero.
Changes are committed straight back to this repository. No code, no
deploy step; the site rebuilds on its own.

## Adding a journey

Admin → Packages → Add a package. Fill it in, set the status to
Published, save. The page appears at `/tours/<slug>/` after the next
build, which runs on every push and every six hours.

## Design tokens

Palette and typography live at the top of `assets/css/style.css`.
Change them there and the whole site follows.

## Known limits

- Video is not hosted here. Use YouTube, Vimeo or Cloudinary and put a
  still image in the hero slides.
- The admin panel needs a GitHub token stored in your browser. See the
  security note in SETUP.md.
- Content edits go live after the next build, typically about a minute.
